# CRISIS-IQ 🚨
AI-Powered Emergency Response Intelligence System

CRISIS-IQ is a smart emergency response system that analyses text emergency reports, detects severity, assigns dynamic priority levels, and recommends emergency dispatch resources in real time.

---

## ✨ Features
- Text emergency reporting
- AI severity detection
- Panic analysis
- Dynamic priority assignment (P1/P2/P3)
- Resource dispatch recommendation
- Live incident dashboard
- Interactive incident map
  
---

## 🛠️ Tech Stack
- Python
- FastAPI
- Streamlit
- SQLite
- SpeechRecognition
- TextBlob
- Folium
